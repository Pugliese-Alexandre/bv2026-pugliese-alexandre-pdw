# DevBoard CLI

Projet réalisé dans le cadre du cours de TypeScript.

J'ai terminé les différentes étapes du DevBoard CLI afin de revoir les bases de TypeScript et de Node.js.

Le projet contient notamment :
- le typage des variables
- les tableaux et les boucles
- une interface `DevProfile`
- des fonctions pour calculer le statut et le score
- une classe `Developer`
- l'utilisation de npm pour compiler et lancer le projet
- le bonus avec une saisie au clavier grâce à `readline/promises`

## Lancer le projet

Installer les dépendances : npm install

Puis lancer le projet : npm run start

Le programme demande le prénom de l'utilisateur puis affiche le profil dans le terminal.
